# Templates

Reusable starting points. A template = a `themeOverride` + director settings + notes, saved as JSON.
Apply one by copying its fields into `work/<reel>/direction.json` (or ask Claude: "use the idea-pitch template").

Rule: templates are starting points, not cages. Each new reel should try at least one improvement and,
if it works, update the template.

- `idea-pitch.json`: casual talking-head idea share (from img-1391).
